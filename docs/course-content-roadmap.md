# Contenidos y prácticas del módulo de cursos

Esta lista reúne los tipos de contenido y actividades incorporados al módulo de cursos de la plataforma.

## Contenidos

1. **Enlaces externos:** artículos, leyes, sitios oficiales y recursos complementarios.
2. **Contenido embebido:** presentaciones, mapas, formularios o herramientas externas.
3. **Material interactivo:** contenido presentado mediante acordeones, pestañas o tarjetas.

## Prácticas y actividades

1. **Casos prácticos:** escenario, contexto y preguntas para tomar decisiones.
2. **Ejercicios de verdadero o falso.**
3. **Relacionar columnas o conceptos.**
4. **Ordenar pasos o acontecimientos.**
5. **Completar espacios.**

## Capacidades implementadas

Todos estos tipos cuentan con:

- Estructura de datos y validación del lado del servidor.
- Configuración visual dentro del constructor de cursos.
- Presentación para estudiantes y registro de finalización.
- Calificación automática e intentos en las prácticas que corresponden.
- Protección de respuestas correctas antes de la entrega del estudiante.
- Restricciones de URL y aislamiento para contenido embebido.

El curso publicado **Tutorial para crear cursos en la plataforma** contiene ejemplos funcionales de cada formato.
